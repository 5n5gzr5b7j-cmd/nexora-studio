3. Vérifie les mentions légales, conditions et obligations applicables à ton activité avant de vendre.

MISE EN LIGNE GRATUITE AVEC GITHUB PAGES :

- Nouveau dépôt public : nexora-studio.
- Ajoute les 3 fichiers.
- Settings > Pages > Deploy from a branch > main.
- Le site sera accessible avec l'adresse GitHub Pages générée.
